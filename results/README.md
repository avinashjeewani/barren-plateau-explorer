# Results folder

Everything here is generated by code. Regenerate it with `make reproduce` (about a minute on a laptop CPU), or rebuild only the tables and chart from the existing CSV with `python -m bpx.report results configs/default.yaml`.

| File | What it contains |
|---|---|
| `gradients.csv` | Raw output: one row per experiment × series × qubit count (72 rows). |
| `summary.md` | Decay table with exponential and power-law fits for every series. |
| `barren_plateaus.png` | Three panels (cost, depth, init) of gradient size vs. qubit count. |

## Columns in `gradients.csv`

| Column | Meaning |
|---|---|
| `experiment` | `cost`, `depth` or `init`. |
| `series` | The configuration within the experiment, e.g. `Global cost`. |
| `n_qubits` | Number of qubits. |
| `n_layers` | Ansatz layers actually used (rounded up to even for identity blocks). |
| `cost` | `global` or `local`. |
| `init` | `uniform`, `small_angle` or `identity_block`. |
| `grad_sq_mean` | E[(∂C/∂θ₁)²], the main metric: typical gradient size. |
| `grad_variance` | Var[∂C/∂θ₁]. Equals `grad_sq_mean` when the mean gradient is zero; zero for identity blocks, whose gradient is the same for every sample. |
| `ci_low`, `ci_high` | 95% bootstrap confidence interval for `grad_sq_mean`. |
| `grad_mean` | Mean gradient across samples. Near zero for uniform random init. |
| `n_samples` | Random initializations per point. |
| `seed` | Random seed for this point. |
| `seconds` | Wall-clock time for this point. |
